# Replication of Card & Krueger (1994)

**"Minimum Wages and Employment: A Case Study of the Fast-Food Industry in New Jersey and Pennsylvania"**

David Card and Alan B. Krueger, *American Economic Review*, 84(4), 1994, pp. 772–793.

This repository is an end-to-end replication of the paper's **Table 2**, **Table 3**,
**Table 4**, and **Figure 1** from the original public dataset, plus one original
extension (heterogeneous difference-in-differences by pre-policy starting-wage
subgroup). Every result is reproduced from raw data with a single command.

---

## 1. Introduction to the replication

### 1.1 The paper

Card and Krueger (1994) study a natural experiment in the US fast-food industry. On
April 1, 1992, New Jersey raised its state minimum wage from **$4.25 to $5.05 per
hour**, while neighboring Pennsylvania kept the federal minimum of $4.25. The authors
surveyed 410 fast-food restaurants in the two states at two points in time:

- **Wave 1** — February 1992 (before the increase);
- **Wave 2** — November 1992 (after the increase).

Using a difference-in-differences (DiD) design, they find that employment in New Jersey
actually *rose* relative to Pennsylvania, contradicting the standard
competitive-labour-market prediction that a binding minimum wage reduces employment.

### 1.2 What this repository reproduces

| Paper object      | Content                                                        | Reproduced as                          |
|-------------------|----------------------------------------------------------------|----------------------------------------|
| Table 2           | Means of key variables (Wave 1 and Wave 2), NJ vs. PA          | `outputs/tables/table2_result.md`      |
| Table 3           | Average employment per store before/after the rise (DiD)       | `outputs/tables/table3_table4_result.md` |
| Table 4           | Reduced-form regression models for the change in employment    | `outputs/tables/table3_table4_result.md` |
| Figure 1          | Distribution of starting wage rates, NJ vs. PA (both waves)    | `outputs/figures/figure1.png`          |

### 1.3 Extension (not in the original paper)

In addition to the four reproduced objects, this project adds a **heterogeneous
difference-in-differences** analysis: the treatment effect of the wage rise is estimated
separately within three pre-policy starting-wage subgroups of New Jersey (low / mid /
high), mirroring the three bins used in the paper's Table 3. Results are in
`outputs/tables/het_did_summary.md` and `outputs/figures/het_did_plot.png`.

## 3. Requirements

- **Python 3.8+** (any modern Python 3.x should work).
- The following Python packages:

  | Package       | Purpose                                    |
  |---------------|--------------------------------------------|
  | `pandas`      | Data loading, cleaning, summarisation      |
  | `numpy`       | Numeric computation                        |
  | `scipy`       | Statistical distributions / tests          |
  | `statsmodels` | OLS regression (Tables 3 & 4, extension)   |
  | `matplotlib`  | Figures (Figure 1, heterogeneous DiD plot) |

Install them with:

```bash
pip install pandas numpy scipy statsmodels matplotlib
```

No GPU, database, or network access is required. All scripts are run from the
**repository root** (the folder that contains `code/`, `data/`, and `outputs/`).

## 4. How to reproduce (feasibility check)

### 4.1 Prerequisites

1. Confirm the raw data exists at `data/raw/public.csv`.
2. Confirm the packages above are installed.

### 4.2 Option A — run the full pipeline (recommended)

From the repository root, run:

```bash
python code/run_all.py
```

This executes the five steps in dependency order and writes all cleaned datasets,
tables, and figures. The console prints a summary after each step and a final
`ALL 5 STEPS FINISHED SUCCESSFULLY!` message.

### 4.3 Option B — run the steps one at a time

Each step is a standalone script in `code/others/` (they read `data/processed/`, so run
the cleaning step first):

| Step | Command                                | Produces                                                        |
|------|----------------------------------------|-----------------------------------------------------------------|
| 1    | `python code/others/clean_data.py`     | `data/processed/cleaned_main.csv`, `data/processed/cleaned_robust.csv` |
| 2    | `python code/others/table2.py`         | `outputs/tables/table2_result.md`                               |
| 3    | `python code/others/table3_table4.py`  | `outputs/tables/table3_table4_result.md`                        |
| 4    | `python code/others/figure1.py`        | `outputs/figures/figure1.png`                                   |
| 5    | `python code/others/het_did.py`        | `outputs/tables/het_did_summary.md`, `outputs/figures/het_did_plot.png` |

> Note: Step 1 (cleaning) is implemented as `run_clean()` inside `run_all.py`; the

## 5. Verification against the paper

The reproduced numbers match the paper's published values almost exactly. The most
important checks:

**Table 3 — difference-in-differences (change in mean FTE, NJ − PA):**

| Quantity                        | Paper      | Reproduction     |
|---------------------------------|------------|------------------|
| Change in mean FTE (NJ − PA)    | 2.76 (1.36)| 2.75 (1.31)      |
| Implied t-statistic             | 2.03       | 2.10             |

**Table 4 — reduced-form models (coefficient on the treatment variable):**

| Model            | Paper         | Reproduction      |
|------------------|---------------|-------------------|
| (i) `nj`         | 2.33 (1.19)   | 2.326 (1.192)     |
| (ii) `nj`        | 2.30 (1.20)   | 2.304 (1.196)     |
| (iii) `gap`      | 15.65 (6.08)  | 15.653 (6.080)    |
| (iv) `gap`       | 14.92 (6.21)  | 14.916 (6.205)    |
| (v) `gap`        | 11.91 (7.39)  | 11.979 (7.419)    |
| Sample size      | 357           | 357               |

**Table 2** — group means also match (e.g. Wave-1 FTE employment: NJ 20.44 vs.
PA 23.33, exactly as in the paper).

**Data sanity checks** — store-closing counts match the paper: 6 closed stores and
4 temporarily-closed stores.

## 6. Summary of results

- The central DiD estimate is **+2.75 FTE employees per store** (SE 1.31), reproducing
  the paper's headline finding that New Jersey employment did **not** fall relative to
  Pennsylvania after the minimum-wage increase.
- The heterogeneous extension shows the effect is **largest (most positive) for the
  lowest-wage subgroup** (DID ≈ +3.22, p ≈ 0.07) and smaller for the mid and high
  subgroups — the opposite of the simple competitive-model prediction and consistent
  with the paper's interpretation.
